# 思考の芽

自分で考えを枝分かれさせ、必要なときだけAIから別の見方を受け取る思考ノートです。

## できること

- ノートを作り、考えとメモを入力する。子の枝・同じ階層の枝を追加する。
- 考えを採用・保留・見送りに分け、判断した理由を残す。
- 枝の開閉、上下の移動、階層の変更、部分表示、削除、取り消し。
- ブラウザ内の自動保存と、全ノートのJSON書き出し・追加読み込み。
- 選んだ枝またはノート全体をAIへ渡す依頼文のコピー。回答JSONを承認待ちとして受け取り、選んだ案だけをツリーに追加する。

初期ノートは操作を試せる固定サンプルです。「取り込みの例を試す」もAIの生成結果ではなく、明示した固定サンプルです。

## ローカル起動

Node.js 22以降で実行します。パッケージのインストールは不要です。

```sh
npm run dev
```

表示先は `http://127.0.0.1:4187`。HTMLファイルの直接ダブルクリックではなく、HTTPサーバー経由で開いてください。

```sh
npm test
```

## 静的な公開

`dist/` は生成物ではなく、直接編集するHTML・CSS・JavaScriptを置いた公開ディレクトリです。ビルドは不要で、`dist/` の内容だけで動きます。ファイル参照はすべて相対パスなので、GitHub Pagesのサブディレクトリにも配置できます。

Nodeの `server.mjs` は開発時の静的配信だけを担当します。公開ページはNodeサーバー・MCP SDK・モデルAPIに依存しません。Sites用の公開先識別情報は `.openai/hosting.json` に分離しています。

## データとAI

保存先は現在の端末・ブラウザ・サイトのURLにひもづくlocalStorageです。アカウントやクラウド同期はありません。別のURLへ公開すると別の保存領域になるため、移行にはJSON書き出し・読み込みを使ってください。

ブラウザのデータ削除やプライベートモードによってノートは失われます。大切な内容は定期的に書き出してください。保存失敗時は入力を保持し、書き出しを案内します。別タブの更新を検知したときは上書きを止めます。ChromeではWeb Locksも使い、保存処理を同じサイト内で直列化します。

AI APIキーは不要です。コピーした依頼文を、自分が利用するAIサービスに貼り付けて相談します。そのサービスの利用枠・料金・データ取り扱いが適用されます。アプリ自体がAIを呼び出したりノートを自動送信したりすることはありません。

対応ブラウザだけで有効になる任意のWebMCP窓口もあります。従来のローカルMCPサーバーとは別の、まだ標準化途中のブラウザAPIです。未対応でもすべての手動機能が動きます。

- `read_selected_thought`: 選択した枝と子孫、祖先の見出しだけを読む。
- `stage_thought_proposals`: 提案を承認待ちに入れる。ツリー本体は変えない。

承認・削除・ノート一覧取得を行うWebMCPツールは公開していません。WebMCPによる実ブラウザの契約テストは未実施であり、必須機能としては扱いません。仕様参照：[WebMCP draft](https://webmachinelearning.github.io/webmcp/)。

## 構成

```text
dist/index.html   画面と入力フォーム
dist/styles.css   共通トークン・PC/スマホのレイアウト
dist/app.mjs      画面の操作・履歴・保存のつなぎ込み
dist/model.mjs    ツリーと提案のルール、JSON検証
dist/storage.mjs  保存・バックアップ・競合検知
tests/           Node標準テスト（外部依存なし）
```
