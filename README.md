# 思考の芽

自分で考えを枝分かれさせ、必要なときだけAIから別の見方を受け取る思考ノートです。

[アプリを開く](https://shiko-no-me-notebook.tokkey20.chatgpt.site/) · [このアイデアが生まれるまでを体験](https://shiko-no-me-notebook.tokkey20.chatgpt.site/?demo=origin)

## できること

- ノートを作り、考えとメモを入力する。子の枝・同じ階層の枝を追加する。
- ボード上でカードを動かし、PCでは四辺の＋、スマホではカードのダブルタップから枝を伸ばす。
- 接続線の色を変える。名前と色を付けた分類枠で複数のカードを囲み、一緒に動かす。
- 考えを採用・保留・見送りに分け、判断した理由を残す。
- 枝の開閉、上下の移動、階層の変更、部分表示、削除、取り消し。
- 左上の←／→で、文章・カードや枠の移動・ボードの表示位置を戻す／やり直す。履歴は現在のページ内で直近40段階。戻した後の新しい編集では、古い「進む」履歴を消します。
- ブラウザ内の自動保存と、全ノートのJSON書き出し・追加読み込み。
- 選んだ枝またはノート全体をAIへ渡す依頼文のコピー。回答JSONを承認待ちとして受け取り、選んだ案だけをツリーに追加する。

初期ノートは操作を試せる固定サンプルです。「取り込みの例を試す」もAIの生成結果ではなく、明示した固定サンプルです。

画面の大部分を自由ボードにし、ノート一覧・整理メニューは左上の「ノート」にまとめています。企画デモは本人の課題・判断をもとに再構成した25枚のカードです。比較のために補った別案はメモに明記し、実際の発言や入力履歴とは区別しています。閲覧専用で順にたどれ、自分のノートへコピーすると編集できます。元のノートやブラウザ内の既存ノートは書き換えません。

## ボードの操作

カードの端の＋（スマホではダブルタップでも可）から、選んだ方向に新しいカードを出します。文章を入力して「追加」かEnterで確定、Shift+Enterで改行、Escape／「やめる」で取り消し。他の操作へ移る際も入力済みなら確定します。空のカードは保存しません。新規入力中は未確定の表示が出ます。

カードをドラッグして移動。余白をドラッグして表示範囲を移動。ホイールはカーソルを中心に拡大縮小し、上下スクロールにはしません。トラックパッドの二本指ピンチは小数の入力量を保って連続的に反映します。＋／−は1.05倍／その逆数ずつ、倍率表示は小数1桁。「全体を見る」で俯瞰し、小さいカードを選ぶと読める大きさへ寄ります。入力欄のスクロールとブラウザの拡大ショートカットは妨げません。

「分類枠で囲む」は選んだ枝とその子孫を囲みます。任意の組み合わせは「複数選択」を有効にしてカードを選んでから囲みます（PCではShiftを押して追加選択も可）。枠の見出しをドラッグすると中身も移動。選択した枠の右下で大きさを調整し、完全に内側に入るカードをその枠の対象にします。枠同士の入れ子所有はありません。枠を外してもカードは消えず、親子関係も変わりません。

線を押すか、カードを選んで「考えを編集」を開くと線の色を変更できます。色は自分の分類用で、採用・保留の判断とは別です。

キーボードではカードのボタンと四辺の追加ボタンをTabでたどれます。カード／枠の見出しにフォーカスしAlt＋矢印で移動、Shiftも押すと大きく移動。枠の右下にフォーカスして矢印でサイズ変更。F2で考えを編集。「一覧で読む」で従来の階層リストに戻れます。

以上は実装した操作です。実ブラウザのクリック・タッチ・日本語IME・画面寸法の検証状況はQA.mdを参照してください。

## ローカル起動

Node.js 22以降で実行します。パッケージのインストールは不要です。

```sh
npm run dev
```

表示先は `http://127.0.0.1:4187`。HTMLファイルの直接ダブルクリックではなく、HTTPサーバー経由で開いてください。

```sh
npm test
```

## 静的な公開

`dist/` は生成物ではなく、直接編集するHTML・CSS・JavaScriptを置いた公開ディレクトリです。ビルドは不要で、`dist/` の内容だけで動きます。ファイル参照はすべて相対パスなので、GitHub Pagesのサブディレクトリにも配置できます。

Nodeの `server.mjs` は開発時の静的配信だけを担当します。公開ページはNodeサーバー・MCP SDK・モデルAPIに依存しません。Sites用の公開先識別情報は `.openai/hosting.json` に分離しています。

## データとAI

保存先は現在の端末・ブラウザ・サイトのURLにひもづくlocalStorageです。アカウントやクラウド同期はありません。別のURLへ公開すると別の保存領域になるため、移行にはJSON書き出し・読み込みを使ってください。

企画デモの共有URLは、アプリに同梱した固定ノートを表示する仕組みです。一般のノートをDBへアップロードする機能、端末ごとの共有3枠、共同編集は未実装です。本人の追加指示により、今回の期限ではDB接続を見送り、共有ボタンにはデモ版で未対応と表示します。DBが規約上禁止されていると断定したものではありません。

ブラウザのデータ削除やプライベートモードによってノートは失われます。大切な内容は定期的に書き出してください。保存失敗時は入力を保持し、書き出しを案内します。別タブの更新を検知したときは上書きを止めます。ChromeではWeb Locksも使い、保存処理を同じサイト内で直列化します。

AI APIキーは不要です。コピーした依頼文を、自分が利用するAIサービスに貼り付けて相談します。そのサービスの利用枠・料金・データ取り扱いが適用されます。アプリ自体がAIを呼び出したりノートを自動送信したりすることはありません。

対応ブラウザだけで有効になる任意のWebMCP窓口もあります。従来のローカルMCPサーバーとは別の、まだ標準化途中のブラウザAPIです。未対応でもすべての手動機能が動きます。

- `read_selected_thought`: 選択した枝と子孫、祖先の見出しだけを読む。
- `stage_thought_proposals`: 提案を承認待ちに入れる。ツリー本体は変えない。

承認・削除・ノート一覧取得を行うWebMCPツールは公開していません。WebMCPによる実ブラウザの契約テストは未実施であり、必須機能としては扱いません。仕様参照：[WebMCP draft](https://webmachinelearning.github.io/webmcp/)。

## 構成

```text
dist/index.html   画面と入力フォーム
dist/styles.css   共通トークン・PC/スマホのレイアウト
dist/board.css    ボード・カード・分類枠のレイアウト
dist/focus.css    ボード中心の全画面表示・引き出しメニュー
dist/story.mjs    会話をもとにした閲覧専用の企画デモ
dist/board-view.mjs ボード描画・ポインター操作・入力中のカード
dist/board-model.mjs 座標・接続線・分類枠の検証と操作
dist/app.mjs      画面の操作・履歴・保存のつなぎ込み
dist/model.mjs    ツリーと提案のルール、JSON検証
dist/storage.mjs  保存・バックアップ・競合検知
dist/history.mjs  元に戻す／やり直す履歴の順序と上限
tests/           Node標準テスト（外部依存なし）
```
