# 添付レビューへの対応

本人から受け取った長文レビューを、v19（2071248）の実装に照合する。レビュー本文にある未実測の指摘を、本人の実操作で観測された事実としては扱わない。

| 指摘 | v19との照合と今回の対応 |
| --- | --- |
| AI画面の段階分け | 反映済み。文脈に合う入口と直リンクからの到達を追加する |
| 返答を持ち帰れない | 厳密な取り込みの検証を保ちながら、原文メモ・候補選択・別用途への明示的切替で復旧できるようにする |
| 自由に広げることと判断が混在 | 普段のボードの未判断ラベルを控える。比較対象や観点の新しい保存モデルは拡張案として残す |
| 深めた理由がまとめに欠落 | コードで確認。各案からつながるカードとメモも含む要約を既定にし、簡潔な出力へ切り替え可能にする |
| 開閉で何が隠れるか不明 | 矢印は反映済み。閉じたカードで先にある全カード数を表示し、操作領域も確認する |
| 内部構造の言葉 | v19で主要説明は修正済み。変更箇所もカード・考え・枝を使い分ける |
| デモから自分の内容へ | コピー機能を維持。空テンプレートと小さな初回体験は今後の拡張案 |
| 未対応の共有を期待させる | 未対応の操作を入口から除き、実際に使える書き出しを維持する |
| AI作業中の保護 | このブラウザで再読み込み後も下書きを復元し、保存不可と破棄の扱いを明示する |
| 比較軸・判断履歴・試した結果 | 今回の中心動線を修復した後の拡張案としてPLAN.mdへ記録 |

## 確認内容

ロジック: 原文保持、異なる追加先への拒否、モード切替候補、複数コードブロック、長さ制限、下書き保存の容量・破損・別タブ競合、関連カードを含む要約、開閉の件数。

視覚・実操作: 文脈別AI入口、返答の復旧から追加/Undo、再読込からの復元/破棄、関連カード付きまとめと簡潔版、開閉と位置の維持。PC/スマホ幅と固定操作の長文スクロールを確認し、実機タッチ/IMEと区別して記録する。

## 実操作の記録

ローカルの既存検証用ノート「休日の小さな計画」を使用。利用者の公開サイトの保存内容は操作していない。

| 操作 | 確認できた結果 |
| --- | --- |
| 自由文 → メモとして確認 → 追加 | 改行を含む原文がメモと一致。追加成功後は下書き一覧から消え、Undoで追加カードだけが消える |
| カード向け依頼に新規ノート用のJSONを貼る | 貼り直さずに新しいノートのプレビューへ進める。2枚のノート作成後、Undoで元の5枚のノートへ戻る |
| 別ノート・別カード宛てのJSON | 原文を保持したまま候補を作らず、追加しない |
| 返答の入力直後に閉じて再読み込み | 返答の原文とカスタム依頼文が復元される |
| 返答を貼る前に依頼文だけを書き、閉じて再読み込み | カスタム依頼文が完全一致し、返答欄は空。依頼文を続ける操作から再開し、破棄後の再読み込みでは再出現しない |
| 複数候補の一部を追加し、閉じて再読み込み | 元の返答は完全一致。追加済みの「川沿いを歩く」は無効になり、未追加の「一枚だけ写真を撮る」は選べる |
| 二つ目の候補を追加してAIを閉じ、Undoして再開 | 取り消した読書案が再び選べる。最初の散歩案の追加済み状態は残る |
| 通常形式のJSONを一部追加し、再読み込み後に残りを追加 | 「窓を開ける」は追加済みで無効、「お茶をいれる」だけを選べる。残りを確定するとダイアログが閉じ、完了した下書きは一覧から消える |
| 関連カードへの相談を保存し、中心カードから再読み込み | 途中の返答一覧から元のカード「外で気分転換」と相談範囲「ノート全体」を復元 |
| 下書きの破棄 | 確認画面で取り消すと入力を保持。破棄すると入力が消え、再読み込み後の一覧にも再出現しない |
| 同じ下書きを別タブで編集 | 先に保存したAを保持。古いタブのBは入力を残して競合を案内し、カード追加も拒否。Aを再読み込みしてAの原文を確認 |
| まとめの関連カード切り替え | 有効時は「川沿いを散歩」「積読を一章読む」を含み、無効時は含まない。案の見出しは両方で保持 |
| 最小カードの開閉 | Enter一回で5枚→1枚→5枚。操作前後の画面位置・大きさが一致。隠れた4枚を表示 |
| 目標デモ・編集用コピー | 閲覧デモの要素は9枚↔1枚で隠れる8枚を表示。編集用73枚の中心カードは閉じると1枚になり、隠れる72枚を表示 |
